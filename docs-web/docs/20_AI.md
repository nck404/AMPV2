## 2. Công cụ Ước lượng Cử chỉ (Fingerpose & Custom Gestures)

Tệp tin [`gestures.js`](file:///D:/Project/AMPV2/source/frontend/amp/src/lib/gestures.js) chứa các định nghĩa cử chỉ tay tự tạo (Custom Gestures) cho toàn bộ bảng chữ cái tiếng Việt và số đếm từ 0-9.

### Cách thức hoạt động
Fingerpose phân tích trạng thái của từng ngón tay dựa trên 2 yếu tố:
1.  **Độ gập (Flexion)**: Ngón tay đang duỗi thẳng (No Flexion), gập một nửa (Half Flexion) hay gập hoàn toàn (Full Flexion).
2.  **Hướng ngón tay (Direction)**: Ngón tay đang chỉ lên trên, chỉ xuống, hướng sang trái/phải hay chéo góc.

### Ví dụ mô tả Cử chỉ Chữ A trong mã nguồn:
```javascript
// Chữ A: Nắm đấm tay, ngón cái duỗi thẳng áp sát bên cạnh
const A_Gesture = new GestureDescription('A');
// Ngón cái duỗi thẳng chỉ lên hoặc chéo
A_Gesture.addCurl(Finger.Thumb, FingerCurl.NoCurl, 1.0);
A_Gesture.addDirection(Finger.Thumb, FingerDirection.VerticalUp, 0.8);
// Các ngón còn lại gập hoàn toàn vào lòng bàn tay
for(let finger of [Finger.Index, Finger.Middle, Finger.Ring, Finger.Pinky]) {
    A_Gesture.addCurl(finger, FingerCurl.FullCurl, 1.0);
}
```

## 3. Quy trình Đánh giá & Phản hồi
- **Confidence Score**: Mỗi cử chỉ nhận diện được gán một điểm số tin cậy từ 0 đến 10. Hệ thống chỉ chấp nhận kết quả khi điểm tin cậy vượt quá ngưỡng thiết lập (thường là 7.5 - 8.0).
- **Phát âm hỗ trợ**: Kết hợp với API TTS để tự động phát âm chữ cái hoặc từ khóa ngay khi người dùng thực hiện cử chỉ chính xác, tạo trải nghiệm tương tác đa giác quan.
